# Release 0.1.4 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship a new release that visibly surfaces OTA ruleset metadata and applies `messageRules` at runtime, with a signed AAB ready for Play Closed Test.

**Architecture:** Keep the OTA ruleset pipeline unchanged except for the new `messageRules` evaluation path and UI metadata exposure. The runtime change stays offline and local: rules are still downloaded, signature-verified, persisted atomically, and consumed by the existing SMS analysis path.

**Tech Stack:** Kotlin, Jetpack Compose, WorkManager, kotlinx.serialization, Gradle Android build.
