# SMS Seguro 0.9.0-beta

## Included changes
- Better detection of Portuguese banking callback scams.
- Clearer PT-PT alert wording.
- Safer fallback text for unknown OTA reasons.
- Visible OTA rules status and version in the Setup screen.
- Option to clear processed history.
- Less aggressive scoring for banking-style messages, reducing false positives.
- OTA ruleset support and recent hardening preserved.

## Why this release matters
- Makes the beta easier to test and explain.
- Reduces noisy alerts without weakening the core banking scam detection path.
- Surfaces OTA rules status so testers can verify the active protection state quickly.
