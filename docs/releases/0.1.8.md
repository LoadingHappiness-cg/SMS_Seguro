# SMS Seguro 0.1.8

## Resumo

Esta versão melhora a experiência dos beta testers sem alterar a arquitetura base da proteção.

## Alterações visíveis

- Modo discreto opcional para a notificação persistente da proteção.
- Motivos de alerta mais claros, sem IDs técnicos na interface.
- Deteção de fraude bancária mais calibrada, com menos falsos positivos.
- Regras OTA mais robustas, mesmo quando existe uma regex malformada.

## Porque esta versão importa

- A proteção continua ativa em segundo plano.
- A interface fica mais limpa e mais fácil de explicar a outros utilizadores.
- A análise passa a ser mais estável e mais confiável para teste beta.
