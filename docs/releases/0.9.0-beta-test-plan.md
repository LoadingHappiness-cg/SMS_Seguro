# Test plan for SMS Seguro 0.9.0-beta

1. Install or update the app from the release artifact.
2. Open the app and confirm the app version is `0.9.0-beta`.
3. Open Setup and confirm the OTA rules status, version, and last-check metadata are visible.
4. Confirm the history clear action is available and works without breaking the current view state.
5. Trigger a manual rules update and confirm the app accepts the signed OTA ruleset path.
6. Send a Portuguese banking callback scam SMS.
7. Expected:
   - high-risk or clearly suspicious alert
   - readable PT-PT alert wording
   - no technical rule IDs exposed in the user-facing alert
8. Send a banking-style SMS that should not be an obvious scam.
9. Expected:
   - no excessive false-positive scoring
   - alert text remains calm and readable
